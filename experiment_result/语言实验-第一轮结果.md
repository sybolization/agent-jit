# 语言实验 第一轮：callable reference 三臂 A/B

日期：2026-08-07 ｜ 模型：DeepSeek deepseek-chat ｜ 样本：每臂 10 次 ｜ 任务：search → map → take → return（同一任务）

## 实验设计

只测一个语法形状变量——map 的 tool 参数表达方式，IR 与 runtime 完全不变：

| 臂 | 表达 | few-shot | allowCallableRef |
|---|---|---|---|
| A | `tool="github.get_repository"` | 无 | false |
| B | `tool="github.get_repository"` | 有 | false |
| C | `tool=github.get_repository` | 无 | true |

原始假设（H4）：C 在 zero-shot 下接近或超过 B → 说明裸标识符（Python-shaped symbol reference）比字符串更贴合模型先验，应进入语言。

## 结果

| 臂 | 成功率 | first-attempt | 成功者平均轮数 | 总轮数 | error 分布 |
|---|---|---|---|---|---|
| A quoted-zero-shot | 0% (0/10) | 0% | — | 50 | syntax=26, undefined_reference=4 |
| B quoted-few-shot | 100% (10/10) | 100% | 1.0 | 10 | 无 |
| C symbolic-zero-shot | 40% (4/10) | 40% | 1.0 | 30 | syntax=12, undefined_reference=6, unknown_parameter=2, unknown_tool=2 |

usage：A input=782 output=570 ｜ B input=1402 output=606 ｜ C input=812 output=653

## 模型实际输出（超出假设的发现）

1. **A 臂没有写裸标识符**：`tool="github.get_repository"` 引号写对了。A 臂全败是因为其他 Python 形状：
   - `details = map(frameworks, tool="...", key="full_name")` —— **map/take 的位置参数**（第一个参数当 source）
   - `return result` —— **无括号 return**
2. **C 臂模型写 `callee=github.get_repository`**：把 Python `map(function, iterable)` 的心智映射成参数名 `callee`（unknown_parameter），并混用位置参数。
3. **EXPECTED_STRING_GOT_CALLABLE_REF 探针 0 次触发**：裸标识符不是稳定摩擦点（最初 anecdote 是偶发，非模型稳定先验）。

## 结论

- **H4 未获支持**：callable reference 表达不是主要摩擦点；真正摩擦点是 **map/take 的位置参数**、**无括号 return**、**参数名（callee 幻觉）**——模型把 DSL construct 直接当 Python 函数调用写。
- **few-shot 完胜**（B 100% vs A 0% vs C 40%）：对当前语法，instruction burden 主要靠 few-shot 解决，而不是语法形状。
- **但实验证实了"Python 先验"大方向**：模型 spontaneously 写 `map(frameworks, ...)` 位置参数，与文档"Python-shaped map"建议一致——只是摩擦不在引号，在**调用形态**。
- **对语言的启示**：如果要降低 friction，优先考虑支持 `map(source, tool, key, concurrency)` 位置参数 + `return x`（无括号），而非 `tool=` 裸标识符。

## 方法论收获

- 受控实验（单变量）+ 保留 rejection 探针有效：数据纠正了假设（friction 位置与预想不同）。
- friction 指标落地：error 分布统计已工作（syntax / unknown_parameter / undefined_reference / unknown_tool 可计数）。

## 下一步候选

1. 第二轮实验：只测 **位置参数 vs 命名参数**（`map(frameworks, ...)` vs `map(source=frameworks, ...)`），同法三臂。
2. 或测 **return 无括号**。
3. 每轮只改一个维度，逐步逼近"模型-native 且静态可分析"的语法面。
