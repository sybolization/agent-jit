  • 逻辑并行度 vs 实际调度：DSL 写 concurrency，runtime 决定真实并发（测试 1/2/5/10 实证）
  • 反转节点数组执行结果一致（调度与顺序解耦）

  • 错误语义是"全有或全无"：任一节点失败即整体失败（V0 明确）

闭环示例（已跑通）

repos = github.search_repositories(query="agent framework", limit=10) details = map(source=repos, tool="github.get_repository", key="full_name", concurrency=5) top = take(source=details, count=5) return(value=top)

编译为 4 个 typed nodes → runtime 真实执行：search 返回 10 条 → map 并发 fan-out 调 get_repository（≤5 并发）→ take 截取 5 条 → return 输出。全程产出 trace，不碰 LLM、不碰真实 API。
